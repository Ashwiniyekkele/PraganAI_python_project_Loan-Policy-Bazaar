# Loan Search and Comparison

A Streamlit-based loan search and comparison application.

## Features

- Home Loan search
- Car Loan search
- Personal Loan search
- Bank comparison
- Interest rate information
- Loan tenure
- Eligibility
- Processing fee
- Policybazaar links
- Official bank links
- CSV download

## Technologies

- Python
- Streamlit
- Pandas
- GitHub
